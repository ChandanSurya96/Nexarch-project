# Go-to-Market

**Purpose:** Launch strategy — how Nexarch gets its first users and its first meaningful community, given the cold-start problem inherent to any discovery/social product. See [user-journey.md](./user-journey.md) for how the Public Investor Library specifically addresses cold start at the product level, and [market-research.md](./market-research.md) for the underlying context this strategy responds to.

---

## The Cold-Start Problem, Named Directly

A discovery feed with no investors in it is worthless, and nobody wants to be the first verified profile on an empty platform. This has to be solved deliberately, not left to organic growth, or Phase 1 risks shipping a product with nothing to discover.

## Strategy

### 1. Seed with the Public Investor Library first
Because these profiles are built from public disclosures rather than requiring any community adoption, the Public Investor Library gives Nexarch something genuinely useful to browse from day one — before a single real user has connected a broker. This is the single most important go-to-market lever available, and it's a product decision as much as a marketing one (see [product-requirements.md](../product-requirements.md)).

### 2. Recruit early verified profiles from existing DIY-investor communities
Target communities where people already discuss and semi-publicly share portfolio approaches: finance-focused subreddits, "fintwit" (finance Twitter/X) India, investing-focused Telegram/Discord groups. The pitch to an early adopter here isn't "grow a following" (there isn't one yet) — it's "get a credible, permanent, verifiable record of what you're already doing," which has value independent of audience size. This aligns well with the Rohan persona in [user-personas.md](./user-personas.md).

### 3. Referral-driven growth for verified profiles
Once there's a real (even small) base of verified profiles, each one is a natural share-and-invite surface — "here's my verified portfolio" is a more credible social artifact than a screenshot, and that credibility gap is the thing worth marketing directly.

### 4. Content/SEO around the Public Investor Library
Educational search intent ("how does [well-known investor] build a portfolio," "[strategy type] investing India") is a plausible organic-acquisition channel once Public Investor Library profiles exist and are well-structured for search — this is a Phase 1/2 content workstream, not a Phase 0 concern, but worth planning for since it depends on Public Investor Library data quality established early.

### 5. Broker partnerships — approach with the same caution as the data-vending question
Given the open question in [broker-integrations.md](../broker-integrations.md) about whether brokers see Nexarch's public-display use case as complementary or as a data-vending concern, any co-marketing conversation with a broker should happen *after*, not instead of, resolving that underlying terms question — leading with a partnership pitch before clarifying the data-use question risks the opposite of the intended goodwill.

## What This Strategy Deliberately Avoids

- **Paid growth/performance marketing** as a Phase 1 lever — premature before the core loop (discover → follow → return) is validated with organic users; spending to acquire users into an unvalidated loop just produces expensive churn data.
- **Influencer partnerships in the traditional sense** — recruiting existing large-following finance creators to promote Nexarch would undercut the entire "credibility through verification, not audience size" positioning, and given the current SEBI scrutiny of finfluencer arrangements (see [market-research.md](./market-research.md)), any paid promotional arrangement with a creator needs the same compliance care as the Creator Economy monetization design itself (see [monetization.md](./monetization.md)) — this is not a channel to reach for casually.
